# 🔌 USB to UART Converter PCB Design (KiCad)

## 📌 Overview
This project presents a custom-designed USB to UART Converter PCB developed using KiCad. It enables seamless communication between a computer and microcontrollers by converting USB signals into UART (serial) signals.

The board is ideal for programming, debugging, and interfacing embedded systems.

---

## ⚙️ Features
- ✅ USB to UART signal conversion  
- ✅ Reliable serial communication  
- ✅ Compact and optimized PCB layout  
- ✅ Supports standard TX/RX interface  
- ✅ Plug-and-play functionality  

---

## 🧠 How It Works
The USB to UART converter acts as a bridge between a computer and a microcontroller:
- The computer sends data via USB  
- The converter chip translates it into UART signals (TX/RX)  
- The microcontroller receives and processes the data  

This also works in reverse for serial monitoring and debugging.

---

## 🔌 Hardware Components
- USB to UART IC (e.g., CH340, CP2102, or FT232RL)  
- USB connector (Micro USB / Type-C)  
- Crystal oscillator (if required by IC)  
- Capacitors and resistors  
- TX/RX header pins  
- Power indicators (LEDs)
